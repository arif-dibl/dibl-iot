Key Technical Observations / গুরুত্বপূর্ণ টেকনিক্যাল পর্যবেক্ষণ

  1. State Management: No global state library — all state in sessionStorage (friendly names cache), localStorage (switch names, widget names), and FastAPI server session (tokens). কোনো গ্লোবাল স্টেট লাইব্রেরি নেই।
  2. API Pattern: FastAPI acts as BFF (Backend For Frontend) — proxies authenticated calls to OpenRemote, manages token refresh, flattens complex data. FastAPI ব্যাকএন্ড BFF হিসেবে কাজ করে।
  3. Real-time: No WebSocket — uses polling (3s intervals). An Android app would benefit from MQTT or WebSocket. কোনো WebSocket নেই — পোলিং ব্যবহার করে।
  4. Offline: Assets offline if last activity > 10 seconds (OFFLINE_TIMEOUT_MS = 10000 in main.js:160). Red cards with disabled controls. অফলাইন অ্যাসেট লাল কার্ড + নিষ্ক্রিয় কন্ট্রোল।
  5. Multi-language: Only device ID instructions bilingual (English/Bangla) — rest is English-only. শুধুমাত্র ডিভাইস ID নির্দেশনা ইংরেজি/বাংলা সাপোর্ট করে।
  6. Security: Session-based auth with auto-refresh, username-matching gatekeeper on all routes, hardcoded admin user (arif) for test API. সেশন-ভিত্তিক অথ + ইউজারনেম-ম্যাচিং গেটকিপার সব রুটে।
